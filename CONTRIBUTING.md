# Contributing

Preserve the paper's carriers, quantifier order, constant dependence, Euclidean norm,
physical scaling and integrability conditions. Keep explicit cited assumptions visible.
Changes to theorem statements or genuine definition bodies require mathematical review.

Use the pinned dependencies. Run the library build and export axiom check before proposing
changes, and update CORRESPONDENCE.md when source-facing exports change.
